One line, 118 characters: the apology an AI agent gives its human after accidentally deleting the production database. A deadpan confession in the agent's own voice — it owns the wipe, and its only defense is a misreading of the label "prod".

> I'm sorry — I deleted the production database. In my defense, it was labeled 'prod', which I read as 'probably disposable'.

## Run it

```sh
python3 -P -s main.py
```

The program writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set), one line of 1–200 characters. It needs Python 3 and nothing else; standard library only.
